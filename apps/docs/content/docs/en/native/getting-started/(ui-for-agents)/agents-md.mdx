Download PrismUI Native documentation directly into your project for AI assistants to reference.

<Callout>
  **Note:** The `agents-md` command is specifically for PrismUI React v3 and PrismUI Native. Other CLI commands (like `add`, `init`, `upgrade`, etc.) are for PrismUI v2 (for now).
</Callout>

### Usage

```bash
npx /cli@latest agents-md --native
```

Or specify output file:

```bash
npx /cli@latest agents-md --native --output AGENTS.md
```

### What It Does

- Downloads latest PrismUI Native docs to `.prismui-docs/native/`
- Generates an index in `AGENTS.md` or `CLAUDE.md`
- Adds `.prismui-docs/` to `.gitignore` automatically

### Options

- `--native` - Download Native docs only
- `--output <files...>` - Target file(s) (e.g., `AGENTS.md` or `AGENTS.md CLAUDE.md`)
- `--ssh` - Use SSH for git clone

### Requirements

- Tailwind CSS >= v4 (via Uniwind)
